FAQ

Frequently asked questions about the icon generator.

This page answers common questions about supported uploads, background removal, export file formats, and how the tool is intended to be used by app teams.

What file should I upload?

A square source image is the easiest starting point. The recommended source is 1024×1024 PNG or larger, but JPG, SVG, and WebP are also supported in the browser workflow.

Does the tool only work for mobile icons?

No. The public workflow supports Android and iOS exports, and it can also generate desktop icon outputs for Windows and macOS.

Can I remove a solid background?

Yes. If the uploaded image has a simple edge-connected background, the optional Remove BG action can make that area transparent. This works best when the background color is relatively uniform around the outer edge.

Will Apple accept a transparent iOS icon?

In general, iOS app icons should not be submitted with transparency. The studio lets users work with transparent artwork internally, but the selected background color should be used when preparing the final icon design for Apple submission.

What does the padding slider change?

Padding controls how much empty space surrounds the visible artwork inside the icon canvas. This helps prevent logos from looking cramped and improves how the icon reads at smaller sizes.

Why preview different icon shapes?

Different launchers and surfaces can mask app icons in different ways. Previewing circle, squircle, and rounded-square variations helps users catch clipping and spacing problems before export.

What is included in the Windows export?

The Windows package includes multiple PNG sizes and a bundled ICO file. This is intended to make the exported files easier to review during desktop development work.

What is included in the macOS export?

The macOS package includes an iconset folder with the expected PNG naming pattern plus an ICNS file for desktop app workflows.

Do I need an account to use the public workflow?

The public site is designed to let users upload, preview, and export without a complex onboarding flow. Some project and analytics data may still be processed so the service can operate correctly.
