The Modern Favicon Guide: SVG, Apple Touch Icons & ICO Standards

Published October 18, 2026 · By Rosdeb Koch · 10 min read

For over a decade, setting up website favicons was notoriously complicated. Developers routinely generated 15 to 20 different icon files—varying from Microsoft tile XML manifests to separate 16px, 32px, 48px, 96px, 128px, and 192px PNG files.

Fortunately, modern web browsers (Chrome, Safari, Edge, Firefox, Opera) have standardized around clean, high-DPI vector rendering. In 2026, you can achieve comprehensive browser, operating system, and mobile device coverage with just **three files** and four lines of HTML.

1. The Minimal Modern Favicon Setup

Instead of cluttering your HTML <head> with dozens of redundant tags, modern best practices recommend the following clean quartet: 

<!-- 1. Legacy fallback for old browsers and desktop shortcuts -->
<link rel="icon" href="/favicon.ico" sizes="any" />

<!-- 2. Modern scalable vector icon (with dark mode support) -->
<link rel="icon" href="/icon.svg" type="image/svg+xml" />

<!-- 3. Apple Touch Icon for iOS Safari and iPadOS bookmarks -->
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />

<!-- 4. Web App Manifest for Android home screen and PWA installs -->
<link rel="manifest" href="/site.webmanifest" />

2. Dynamic Dark Mode Favicons Using SVG

Because SVG files can include embedded CSS styles, you can automatically adapt your tab icon to the user's operating system dark mode theme! This ensures a dark brand icon doesn't vanish against a dark browser tab bar: 

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <style>
    path { fill: #1a2130; }
    @media (prefers-color-scheme: dark) {
      path { fill: #ffffff; }
    }
  </style>
  <path d="M50 15 L85 85 L15 85 Z" />
</svg>

Why you still need favicon.ico in your root

Even with SVG support, web crawlers, search engines (Googlebot), and older RSS readers request /favicon.ico directly at your domain root without reading your HTML header. Always provide a multi-size favicon.ico containing 16×16 and 32×32 pixel layers.

4. Complete Favicon Size Reference

While the modern minimal setup covers most scenarios, here's the full matrix of favicon sizes and where each one is used across different platforms and contexts:

  • 16×16 px: Browser tab icon (the classic favicon size, still used by all browsers).
  • 32×32 px: Windows taskbar shortcut, Safari Reading List, some browser address bars.
  • 48×48 px: Windows desktop shortcut (DPI-independent).
  • 96×96 px: Google TV, some Android Chrome contexts.
  • 180×180 px: Apple Touch Icon for iOS Safari home screen bookmarks and iPadOS.
  • 192×192 px: Android Chrome home screen shortcut, PWA manifest minimum.
  • 512×512 px: PWA splash screen, some app store listings.
  • SVG (scalable): Modern browsers, renders pixel-perfectly at any size.

5. Dark Mode Favicon Best Practices

With the majority of developers and users now preferring dark mode interfaces, your favicon needs to be visible and attractive in both light and dark browser chrome. Here are the key strategies:

  • SVG with media queries (shown above) is the cleanest solution. It adapts automatically without any JavaScript.
  • Avoid pure white or pure black logos in your favicon. White vanishes against light browser tabs; black vanishes against dark tabs. Use slightly off-white (#f0f0f0) or slightly off-black (#1a1a1a) to maintain visibility in both modes.
  • Add a subtle border or background to your SVG favicon. A thin semi-transparent border ensures your icon has visible boundaries regardless of the surrounding chrome color.
  • Test in both modes: Open your site in Chrome or Firefox, toggle the system dark mode setting, and verify your favicon remains legible in the tab bar.

6. Common Favicon Mistakes to Avoid

  • Using only a single .ico file with one resolution: A 16×16-only favicon looks blurry on retina displays and high-DPI bookmarks. Always include at least 16×16 and 32×32 layers.
  • Placing favicon.ico in a subdirectory: Many crawlers and older browsers hard-request /favicon.ico at the domain root. Always keep a copy there.
  • Using JPEG instead of PNG for raster favicons: JPEG compression artifacts are extremely visible at 16×16 and 32×32 sizes. Always use PNG or ICO format for raster favicons.
  • Forgetting the web app manifest: Android Chrome ignores <link rel="icon"> for home screen shortcuts and uses only the manifest icons array. Without a manifest, Android falls back to a generic globe icon.
  • Overly complex designs: Your favicon displays at 16×16 pixels in browser tabs. At that scale, only the simplest shapes remain recognizable. Use your brand's most reduced symbol — not your full logo.

7. Testing Your Favicon Implementation

After implementing your favicon suite, validate it across these surfaces:

  • Desktop browser tabs: Chrome, Firefox, Safari, and Edge on both light and dark mode.
  • Mobile Safari bookmark: Add your site to the iOS home screen and verify the Apple Touch Icon renders correctly.
  • Android Chrome home screen: Add your site to the Android home screen via "Add to Home Screen" and check the manifest icon.
  • Google search results: Google displays favicons next to search results. Verify yours appears correctly by searching for your site.
  • Bookmarks and reading lists: Add your site to bookmarks in multiple browsers and check the icon quality.
  • Social sharing: While not technically a favicon, your og:image meta tag should use a higher-resolution version of your brand mark for social media preview cards.
