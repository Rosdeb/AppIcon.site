Progressive Web App (PWA) Icon Guide: Manifest, Maskable Icons & Best Sizes

Published September 28, 2026 · By Rosdeb Koch · 12 min read

Progressive Web Apps (PWAs) bridge the gap between traditional websites and native mobile applications. When a user taps "Install" or "Add to Home Screen" in Google Chrome, Safari, Edge, or Firefox, the browser relies on your manifest.json (or site.webmanifest) to construct native home screen launchers, splash screens, and app switcher entries.

Configuring your PWA icon array improperly can cause jarring letterboxing, blurry splash screens, or automatic failure of Lighthouse PWA installation audits. In this guide, we explore the required icon sizes, explain how maskable icons prevent unsightly white backgrounds on Android, and show you how to write clean manifest entries.

1. The Two Core Sizes: 192×192px and 512×512px

At minimum, every installable Progressive Web App must supply two square PNG assets:

  • 192×192 px: Displayed on mobile home screens (Android, iOS Home Screen shortcuts, ChromeOS app drawer).
  • 512×512 px: Utilized by the browser to generate the automatic splash screen during launch, as well as the app installation prompt banner.

2. Understanding Maskable Icons (purpose: "maskable")

On Android devices with adaptive icons, if you submit a transparent PNG with "purpose": "any", Android cannot guess what shape to apply. To prevent ugly clipping, Android places your icon inside a tiny white circular badge.

To deliver a full-bleed, edge-to-edge native appearance, Google created the Maskable Icon standard. A maskable icon is an edge-to-edge graphic with a background color where the central logo is kept strictly within the minimum safe zone: an inner circle with a radius equal to 40% of the canvas size (or 80% diameter centered).

The Maskable Safe Zone Formula

For a 512×512px maskable icon, keep all critical logo artwork within a 410×410px centered circle. The outer 51px margin on all sides will be trimmed depending on whether the user's phone uses circular, squircle, or rounded square launcher shapes.

3. Production-Ready Web App Manifest Template

Here is the recommended site.webmanifest configuration combining both standard and maskable icons: 

{
  "name": "My Progressive Web App",
  "short_name": "MyPWA",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#5a78e8",
  "icons": [
    {
      "src": "/icons/icon-192x192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/icons/icon-192x192-maskable.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "maskable"
    },
    {
      "src": "/icons/icon-512x512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/icons/icon-512x512-maskable.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "maskable"
    }
  ]
}

4. Don't Forget Safari iOS: Apple Touch Icon

iOS Safari does not read the Web App Manifest for its home screen bookmark icon. Instead, you must specify the Apple touch icon tag inside your HTML <head>: 

<link rel="apple-touch-icon" href="/icons/apple-touch-icon.png" />

The recommended resolution is 180×180 pixels (or 1024×1024 downscaled). Remember that iOS automatically applies continuous rounded corners, so the source file must be a solid, non-transparent square.

6. Designing Effective Maskable Icons: Step-by-Step

Creating a maskable icon that looks professional across all Android launcher shapes requires careful attention to the safe zone. Here's a practical workflow:

  1. Start with a 512×512 canvas in your design tool (Figma, Sketch, or Adobe Illustrator).
  2. Fill the entire canvas with your brand's primary background color. No transparency — the entire square must be opaque.
  3. Draw the safe zone circle — a centered circle with 204px radius (408px diameter) on the 512px canvas. This represents the 80% safe area.
  4. Place your logo or glyph entirely within this circle. Leave additional internal padding (about 10-15%) for visual breathing room.
  5. Test with shape overlays — preview your icon under circle, squircle, rounded square, and teardrop masks to verify nothing important gets clipped.
  6. Export as PNG with no transparency. The file must be exactly 512×512 pixels.

7. Splash Screen Generation from PWA Icons

When a user launches an installed PWA, most browsers generate an automatic splash screen using three manifest properties:

  • name — displayed as the app title on the splash screen.
  • background_color — fills the splash screen background.
  • icons (512×512) — the largest icon is centered on the splash screen above the app name.

If your 512px icon has excessive padding, transparent backgrounds, or low contrast against the specified background color, the splash screen will look unfinished and unprofessional. Always test the splash screen appearance by installing your PWA on a real Android device or Chrome DevTools device emulator.

8. Lighthouse PWA Icon Audit Requirements

Google's Lighthouse audit tool (built into Chrome DevTools) checks specific PWA installability criteria. For icons, Lighthouse verifies:

  • At least one icon of 192×192px or larger exists in the manifest
  • At least one icon of 512×512px or larger exists for the splash screen
  • Icons are accessible (HTTP 200 response) and valid image files
  • At least one maskable icon is provided (for the "maskable icon" audit)
  • The manifest start_url responds with HTTP 200 when offline (service worker cache)

Failing any of these checks will flag your PWA as "not installable" in Lighthouse, which can affect search engine ranking signals and prevent the browser from showing the native install prompt.

Quick PWA Icon Checklist

✓ 192×192 and 512×512 PNG icons in manifest
✓ Separate maskable versions with "purpose": "maskable"
✓ Logo within 80% centered safe zone on maskable icons
✓ 180×180 Apple touch icon in HTML <head>
✓ Opaque backgrounds on all icons (no transparency)
✓ background_color matches your icon's background
✓ Tested splash screen on real Android device
✓ All Lighthouse PWA installability audits passing
