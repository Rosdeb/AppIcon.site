Progressive Web App (PWA) Icon Guide: Manifest, Maskable Icons & Best Sizes

Published September 28, 2026 · By Rosdeb Koch · 7 min read

Progressive Web Apps (PWAs) bridge the gap between traditional websites and native mobile applications. When a user taps "Install" or "Add to Home Screen" in Google Chrome, Safari, Edge, or Firefox, the browser relies on your manifest.json (or site.webmanifest) to construct native home screen launchers, splash screens, and app switcher entries.

Configuring your PWA icon array improperly can cause jarring letterboxing, blurry splash screens, or automatic failure of Lighthouse PWA installation audits. In this guide, we explore the required icon sizes, explain how maskable icons prevent unsightly white backgrounds on Android, and show you how to write clean manifest entries.

1. The Two Core Sizes: 192×192px and 512×512px

At minimum, every installable Progressive Web App must supply two square PNG assets:

  • 192×192 px: Displayed on mobile home screens (Android, iOS Home Screen shortcuts, ChromeOS app drawer).
  • 512×512 px: Utilized by the browser to generate the automatic splash screen during launch, as well as the app installation prompt banner.

2. Understanding Maskable Icons (purpose: "maskable")

On Android devices with adaptive icons, if you submit a transparent PNG with "purpose": "any", Android cannot guess what shape to apply. To prevent ugly clipping, Android places your icon inside a tiny white circular badge.

To deliver a full-bleed, edge-to-edge native appearance, Google created the Maskable Icon standard. A maskable icon is an edge-to-edge graphic with a background color where the central logo is kept strictly within the minimum safe zone: an inner circle with a radius equal to 40% of the canvas size (or 80% diameter centered).

The Maskable Safe Zone Formula

For a 512×512px maskable icon, keep all critical logo artwork within a 410×410px centered circle. The outer 51px margin on all sides will be trimmed depending on whether the user's phone uses circular, squircle, or rounded square launcher shapes.

3. Production-Ready Web App Manifest Template

Here is the recommended site.webmanifest configuration combining both standard and maskable icons: 

{
  "name": "My Progressive Web App",
  "short_name": "MyPWA",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#5a78e8",
  "icons": [
    {
      "src": "/icons/icon-192x192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/icons/icon-192x192-maskable.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "maskable"
    },
    {
      "src": "/icons/icon-512x512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any"
    },
    {
      "src": "/icons/icon-512x512-maskable.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "maskable"
    }
  ]
}

4. Don't Forget Safari iOS: Apple Touch Icon

iOS Safari does not read the Web App Manifest for its home screen bookmark icon. Instead, you must specify the Apple touch icon tag inside your HTML <head>: 

<link rel="apple-touch-icon" href="/icons/apple-touch-icon.png" />

The recommended resolution is 180×180 pixels (or 1024×1024 downscaled). Remember that iOS automatically applies continuous rounded corners, so the source file must be a solid, non-transparent square.
