The Modern Favicon Guide: SVG, Apple Touch Icons & ICO Standards

Published October 18, 2026 · By Rosdeb Koch · 6 min read

For over a decade, setting up website favicons was notoriously complicated. Developers routinely generated 15 to 20 different icon files—varying from Microsoft tile XML manifests to separate 16px, 32px, 48px, 96px, 128px, and 192px PNG files.

Fortunately, modern web browsers (Chrome, Safari, Edge, Firefox, Opera) have standardized around clean, high-DPI vector rendering. In 2026, you can achieve comprehensive browser, operating system, and mobile device coverage with just **three files** and four lines of HTML.

1. The Minimal Modern Favicon Setup

Instead of cluttering your HTML <head> with dozens of redundant tags, modern best practices recommend the following clean quartet: 

<!-- 1. Legacy fallback for old browsers and desktop shortcuts -->
<link rel="icon" href="/favicon.ico" sizes="any" />

<!-- 2. Modern scalable vector icon (with dark mode support) -->
<link rel="icon" href="/icon.svg" type="image/svg+xml" />

<!-- 3. Apple Touch Icon for iOS Safari and iPadOS bookmarks -->
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />

<!-- 4. Web App Manifest for Android home screen and PWA installs -->
<link rel="manifest" href="/site.webmanifest" />

2. Dynamic Dark Mode Favicons Using SVG

Because SVG files can include embedded CSS styles, you can automatically adapt your tab icon to the user's operating system dark mode theme! This ensures a dark brand icon doesn't vanish against a dark browser tab bar: 

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <style>
    path { fill: #1a2130; }
    @media (prefers-color-scheme: dark) {
      path { fill: #ffffff; }
    }
  </style>
  <path d="M50 15 L85 85 L15 85 Z" />
</svg>

Why you still need favicon.ico in your root

Even with SVG support, web crawlers, search engines (Googlebot), and older RSS readers request /favicon.ico directly at your domain root without reading your HTML header. Always provide a multi-size favicon.ico containing 16×16 and 32×32 pixel layers.
